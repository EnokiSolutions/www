Max for Live device

MIDI Pass Lowest Note Only

A small MIDI effect for Ableton Live that turns any polyphonic MIDI — wherever notes overlap — into a single line by passing only the lowest held note — with optional keyswitch stripping.

  • Built for pitch-following plugins

    Made to feed MIDI into Aeons Light EQ, which can follow MIDI notes. Put the device on the track playing the part, followed by Ableton's External Instrument device with its MIDI output routed to the EQ — no separate MIDI track to keep in sync when the part changes.

    Add Ableton's Pitch device set to −12 st before the External Instrument. There's no agreed standard for whether MIDI note 60 is C3, C4, or C5, and Live and the EQ number octaves one apart, so without the offset the EQ tracks an octave high.

  • Lowest note only

    When on, only the lowest held note is output, making any part monophonic. Handy for driving a bass line or mono synth from any polyphonic part.

  • Strip keyswitches

    Notes below Keyswitch Low (default C1) or above Keyswitch High (default F6) are treated as keyswitches and removed, so articulation changes don't reach the instrument.

  • Pass-through when off

    With both buttons off, the device passes all MIDI through untouched.

Free download, version 1. Requires Ableton Live 12.4.5 or later with Max for Live (Max 9).
