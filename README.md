# www

Enoki Solutions Inc. company site, built with [Astro](https://astro.build).

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

This writes the static site to `docs/`, which GitHub Pages serves directly (custom domain `www.enoki.ca`, see `public/CNAME`). Commit the rebuilt `docs/` folder along with any `src/` changes.
